# QPlayer 解锁下载插件

不提供歌曲搜索。需要先安装并启用 **QQ 音乐** 或 **网易云音乐** 之一。用对应音源搜歌，然后：

- 列表右键 **下载**，再选音质（128k / 192k / 320k / 无损 / Hi-Res）
- 歌单每一行右侧的 **下载** 按钮（安装本插件后出现）
- 或播放页 **下载当前**，同样选档

宿主按播放同一条 `resolveStream` 拉流，弹出保存框写成 `歌名 - 歌手.mp3`（或 flac/m4a）。音源没有该档时落到它能给的最高可用地址。需要带 `files.save` 的 QPlayer（本仓库 `D:/desktop/qplayer`）。

「缓存此歌曲」仍是内部离线副本。
